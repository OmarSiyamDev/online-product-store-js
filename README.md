# Online Product Store (CRUD Application)

A dynamic front-end web application for managing products, integrated with a REST API to perform full CRUD operations.

## Features
- **CRUD Operations:** Create, read, update, and delete products using asynchronous REST API requests
- **Product Filtering:** Filter products by category and availability
- **Dynamic UI:** Render product cards and status badges, updating the interface dynamically using the DOM
- **ES6 Modules:** Code organized into separate modules for API, UI, utilities, and main application logic
- **Error Handling:** Manage errors and loading states using `try`, `catch`, and `finally`
- **Input Validation:** Validate user input, including price formatting using Regular Expressions (RegEx)

## Technologies
- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API / async-await
- REST API

## Project Structure
| File / Folder | Description |
|---|---|
| `index.html` | Main page: product list and filters |
| `add-product.html` | Page for adding a new product |
| `edit-product.html` | Page for editing an existing product |
| `css/` | Stylesheets |
| `js/` | JavaScript modules (API, UI, utilities, main logic) |

## How to Run
1. Clone the repository:
```bash
   git clone https://github.com/OmarSiyamDev/online-product-store-js.git
```
2. Open the project folder in VS Code.
3. Run `index.html` with the **Live Server** extension
   (ES6 modules require a local server and will not work by double-clicking the file).
